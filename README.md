## 📌 Project Overview
Developed an enterprise-grade Business Insights dashboard in Power BI to track cross-functional performance across Finance, Sales, Marketing, and Supply Chain operations for a hardware manufacturing company. This project replaced static reporting with an automated, 360-degree analytics tool to enable rapid, data-driven decision-making for executive stakeholders.

## 🛠️ Tech Stack
- **Business Intelligence Tool:** Microsoft Power BI
- **ETL & Data Cleaning:** Power Query
- **Data Modeling:** Star Schema (Fact & Dimension Tables)
- **Calculations & Logic:** Advanced DAX (Data Analysis Expressions)

## 📊 Key Features & Reporting Views
1. **Finance View:** Dynamic Profit and Loss (P&L) statements tracking Net Sales, Cost of Goods Sold (COGS), Gross Margin, and Net Profit across regions and time periods.
2. **Sales View:** Customer-level and product-level performance tracking to identify regional sales leaders and underperforming segments.
3. **Marketing View:** Profitability analysis targeting gross margin margins to evaluate marketing campaign efficiency and pricing strategies.
4. **Supply Chain View:** Operational metrics tracking forecast accuracy, net error, and inventory bottlenecks to optimize distribution logistics.

## ⚙️ Technical Competencies Demonstrated
- **Data Modeling:** Engineered a robust relational data model connecting millions of rows of sales, financial, and operational data.
- **Advanced DAX:** Built complex measures using Time Intelligence, `CALCULATE`, variables, and context transition functions.
- **UI/UX Design:** Designed an intuitive, high-contrast user interface with interactive bookmarks, tooltips, and dynamic page navigation for seamless executive use.

---
*Note: This project was completed as part of an intensive Data Analytics program, utilizing raw operational data to solve real-world FMCG bottlenecks.*
